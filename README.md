# Restaurant Page

A dynamically rendered restaurant website built with JavaScript, Webpack, and CSS. This project is part of The Odin Project curriculum.

## 📝 Description

This application demonstrates DOM manipulation by generating the entire homepage content using JavaScript. It features tabbed navigation to switch between different sections (Home, Menu, Contact) without reloading the page.

## 🚀 Features

- **Dynamic Content Generation:** No HTML code in `index.html` (except the container div); all elements are created via JavaScript.
- **Tabbed Navigation:** Seamless switching between content modules.
- **Webpack Bundling:** Uses Webpack to bundle JavaScript modules and assets.
- **ES6 Modules:** Organized code structure separating logic for different pages.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Webpack**
